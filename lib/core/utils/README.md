# utils

Folder ini menyimpan fungsi-fungsi pembantu (helper/utility) yang bersifat umum dan bisa dipakai di mana saja. Contohnya: format angka ke format mata uang Rupiah, format tanggal, atau generator UUID untuk id lokal sebelum sync ke server. File di sini harus stateless — hanya fungsi murni tanpa side effect.

Contoh file: `currency_formatter.dart`
