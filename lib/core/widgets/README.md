# widgets

Folder ini menyimpan widget Flutter yang dipakai ulang di banyak halaman (global/shared widgets). Widget di sini tidak boleh punya BLoC atau business logic sendiri — hanya menerima data lewat parameter dan menampilkan UI. Contohnya: tombol standar, text field, loading overlay, atau tampilan kosong (empty state).

Contoh file: `app_button.dart`
