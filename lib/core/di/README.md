# di

Folder ini menyimpan konfigurasi Dependency Injection (DI) menggunakan `get_it` dan `injectable`. File `injection.dart` adalah entry point untuk mendaftarkan semua service, repository, dan usecase ke dalam service locator. File `injection.config.dart` di-generate otomatis oleh `build_runner` — jangan edit manual.

Contoh file: `injection.dart`
