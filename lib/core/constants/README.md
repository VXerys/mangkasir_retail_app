# constants

Folder ini menyimpan nilai-nilai tetap (konstanta) yang dipakai di seluruh aplikasi, seperti warna, teks statis, dan style teks. File di sini tidak boleh berisi logic — hanya definisi nilai. Contoh: warna tombol, ukuran font, atau label teks yang dipakai berulang.

Contoh file: `app_colors.dart`
